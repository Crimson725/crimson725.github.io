Zhixin Zeng 曾智鑫

Independent Researcher

I work on machine learning and reinforcement learning. My current research is on agents for video editing: giving an agent the checks, feedback, and editable history that coding agents already get from compilers and version control. Earlier, I worked on inverse reinforcement learning for urban safety perception and on fake news detection. I hold an M.S. in Computer Science from Northeastern University and a B.S. from Sichuan University.

Projects

  • Cassette

    A video editor in which people and agents make edits through the same path, available as a macOS app and a browser editor. Co-founder and primary developer.

    Access is invite-only. If I emailed you, that address already has access; otherwise, email me for an invite. The macOS app (Apple silicon, macOS 15 or later) is the more complete version. Without an account, you can watch the demo videos: a screen recording of an editing session and the video it produced.

  • oh-my-cassette

    An open-source plugin that connects coding agents, including Claude Code and Codex, to the Cassette editor.
